Endpoint defense built for operators, not dashboards.

ByteWorthy Defend is an open-source terminal antivirus for Windows and Linux. It combines deterministic scanning, quarantine lifecycle controls, reversible firewall operations, and optional AI remediation that never bypasses policy.

Maintained in public by ByteWorthy and the open-source community.

What You Get

Two editions in one repository with explicit policy boundaries.

Core Edition

  • Signature/rule scanning engine
  • Quarantine list/restore/purge lifecycle
  • Rules checksum + schema verification
  • Audit-chain verification for tamper evidence
  • Monitor/firewall/process controls with JSON output

AI Edition

  • Policy-gated remediation planning and execution
  • Operator approval workflow for destructive actions
  • Audit records for proposed and executed steps
  • Confidence thresholds for non-destructive automation

Production Operations

  • Strict health gate: bw-defend doctor --strict --json
  • Workflow-based release readiness checks
  • Security, threat model, and runbook documentation
  • Machine-readable exit codes for CI and SOC pipelines

Stable CLI Surface

All operational commands support --json for automation.

bw-defend scan <path|system>
bw-defend monitor start|stop|status
bw-defend quarantine list|restore|purge
bw-defend firewall status|apply|revert
bw-defend process list|kill --pid <id> --approve
bw-defend ai remediate <incident-id> [--approve]
bw-defend rules update|list|verify
bw-defend audit verify [--log-path <path>]
bw-defend doctor [--strict]

Operator FAQ

Who is ByteWorthy Defend built for?

Windows and Linux platform security teams that need scriptable, auditable host defense controls from the terminal.

What is included in the current project release?

Core scan/quarantine/rules/firewall/process controls and optional AI remediation with policy gating and approval paths.

What is not included?

macOS support is out of scope for v1. Project release scope is Windows and Linux.

Is this a managed antivirus service?

No. This is an open-source project/tool. Use at your own discretion and risk. No security outcome is guaranteed.

How do I verify readiness fast?

Run bw-defend doctor --strict --json, then validate docs and tests using repository workflows and runbooks.
