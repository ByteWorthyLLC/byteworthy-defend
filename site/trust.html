ByteWorthy Defend Trust Center

This page centralizes security controls, release controls, and disclosure channels for ByteWorthy Defend. Claims below are mapped to public repository evidence.

Repository · Security Policy · Release Readiness

Security Controls

  • AI remediation never bypasses policy controls.
  • Destructive actions require explicit operator approval when policy requires it.
  • Rule updates require integrity and schema validation before activation.
  • Optional detached rule signatures can be enforced for updates.
  • Proposed and executed actions are written to hash-chained audit records.

Operational Behaviors

  • Stable command surface for production scripts.
  • --json output across operational commands.
  • Strict readiness gate: bw-defend doctor --strict --json.
  • Reversible monitor and firewall transitions.

Disclosure Process

Report vulnerabilities through GitHub Security Advisories or email security@byteworthy.io.

Public issue trackers should not be used for exploitable vulnerability details.

Scope Clarifications

  • Project release scope is Windows and Linux.
  • macOS support is not part of v1 scope.
  • AI capabilities are optional by dependency and configuration.

OSS Disclaimer

ByteWorthy Defend is an open-source project/tool. Use is at your own discretion and risk. No security outcome is guaranteed.
