# GitHub Hardening Baseline

## Repository Controls

- default branch: `main`
- branch protection on `main` with required status checks
- signed commit preference where feasible
- dependency alerts enabled
- secret scanning enabled

## Required Checks

- `CI`
- `Security`
- `Release Readiness`

## Governance Files

- `CONTRIBUTING.md`
- `SECURITY.md`
- `.github/SECURITY.md`
- `.github/CODEOWNERS`
- issue and PR templates
