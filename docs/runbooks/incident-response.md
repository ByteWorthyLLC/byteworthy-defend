# Runbook: Incident Response

## Initial Actions

1. identify artifact and severity
2. isolate with quarantine where safe
3. capture incident and audit evidence
4. determine if AI remediation is allowed by policy

## Decision Path

- if destructive action is needed, require explicit operator approval
- if confidence below threshold, escalate to human review

## Closure

- update incident final outcome
- preserve logs
- record lessons learned and policy updates
