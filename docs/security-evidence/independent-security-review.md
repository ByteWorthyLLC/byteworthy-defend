# Security Evidence: Independent Security Review

Status: `Optional - Continuous assurance`

## Purpose

Independent third-party security reviews (not performed by repository maintainers) are recommended as part of continuous assurance.

## Suggested Deliverables

- Penetration test executive summary
- Findings list with severity and reproduction notes
- Remediation verification report
- Reviewer attestation letter

## Suggested Exit Criteria

- No unresolved critical findings
- High findings have approved mitigation or remediation
- Report link attached to release notes when a review is performed
