# ==========================
# USAGE TIPS
# ==========================

# 1. Be specific: "show me PowerShell alerts today" is better than "show alerts"
# 2. Use time qualifiers: "today", "yesterday", "this week", "last hour"
# 3. Specify threat types: "ransomware", "trojan", "cryptominer", etc.
# 4. Ask follow-up questions based on answers you receive
# 5. Combine concepts: "show me high-priority PowerShell threats from today"

# ==========================
# NOTES
# ==========================

# - Queries require ChromaDB to be installed
# - First query may take 5-10 seconds (database initialization)
# - Subsequent queries are faster
# - Queries are cached for 24 hours by default
# - Cost per query: approximately $0.001-0.005

# ==========================
# EXAMPLES OF GOOD QUERIES
# ==========================

# ✓ "what PowerShell scripts were flagged as malicious today?"
# ✓ "show me all high-severity threats from the last 24 hours"
# ✓ "did you detect any ransomware this week?"
# ✓ "what domains were blocked in the last hour?"
# ✓ "summarize today's security events by threat type"

# ==========================
# EXAMPLES OF BAD QUERIES
# ==========================

# ✗ "stuff" (too vague)
# ✗ "yes" (not a question)
# ✗ "..." (no content)
# ✗ "how are you?" (social, not security-related)
# ✗ "make me a sandwich" (not security-related)
